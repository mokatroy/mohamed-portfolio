# موقع بورتفوليو — محمد عبد العزيز

موقع شخصي لمونتير فيديو: شوريل، شبكة أعمال بفلاتر، صفحة خدمات، نبذة، وتواصل.
مبني بـ React + Vite + Tailwind، وكل حاجة تقدر تعدّلها من غير ما تلمس كود.

---

## ١) تشغيل الموقع على جهازك

محتاج [Node.js](https://nodejs.org) نسخة 18 أو أحدث.

```bash
npm install     # مرة واحدة بس
npm run dev     # يفتح الموقع على http://localhost:3000
```

لو عايز نسخة جاهزة للنشر:

```bash
npm run build   # بيطلع فولدر dist
npm run preview # تشوف نسخة dist قبل النشر
```

## ٢) إزاي تحط شغلك (أهم جزء)

### أ) الفيديوهات — فولدر `public/videos/`

الفيديوهات اللي موجودة دلوقتي **ديمو مؤقت** (مولّدة) عشان تشوف شكل الموقع.
امسحها وحط شغلك:

1. حط الفيديو في `public/videos/` — مثال: `public/videos/قهوة-الشرق.mp4`
   (يفضّل أسماء إنجليزي من غير مسافات، مثلاً `coffee-ad.mp4`).
2. حط صورة بوستر من الفيديو بنفس الاسم: `public/videos/coffee-ad.jpg`
   (صورة من منتصف الفيديو، 1920×1080 تقريباً).
3. افتح `src/data/projects.js` وانسخ بلوك مشروع وحطه في آخر القايمة:

```js
{
  id: "coffee-ad",                       // اسم مميز مش متكرر
  title: "قهوة الشرق — إعلان",           // اللي يظهر على الكارت
  client: "اسم العميل",                  // أو "شغل خاص"
  category: "ads",                       // ads | social | music | film | motion
  year: "2026",
  size: "wide",                          // wide | half | narrow
  video: "/videos/coffee-ad.mp4",
  poster: "/videos/coffee-ad.jpg",
  duration: "00:32",
  role: ["مونتاج", "تصحيح ألوان"],
  description: "سطرين عن الفيديو: إيه اللي عملته فيه ونتيجته.",
}
```

نصايح فنّية للفيديو:
- **mp4 / H.264** هو أضمن فورمات لكل الأجهزة.
- خلّي الفيديو **أقل من 15–20 ميجا** للعرض على الموقع (ويب مش يوتيوب).
  لو كبير: اعمله export 1080p بجودة متوسطة، أو ارفعه على YouTube/Vimeo
  وحط اللينك مكان `video` (يشتغل عادي بس من غير لوب).
- أول ٣ ثواني هي اللي بتبيع — اختار ستارت قوي لكل فيديو.

بالنسبة للفيديوهات العمودية (ريلز/تيك توك) ارفعها عادي، و`size: "narrow"` بتخلي
الكارت طويل زي ما هو مناسب.

### ب) الشوريل

في `src/data/site.js`:

```js
showreel: {
  src: "/videos/showreel-reel.mp4",
  poster: "/videos/showreel-reel.jpg",
  duration: "01:12",
  subtitle: "أحسن دقيقة عندي — كل حاجة في فيديو واحد.",
  specs: ["4K", "24 FPS", "COLOR GRADED"],
}
```

نفس مكان الفولدر `public/videos/`. بيظهر في الهيرو كخلفية، وفي قسم الشوريل،
وفي البلاير اللي بيفتح بالصوت.

### ج) صورك وصورة البورتين

- صورتك: حطها في `public/images/portrait.jpg` (مقاس ٤:٥، مثلاً 800×1000).
  لو مش موجودة بيظهر مكانها تصميم حروف `MAA` — يعني مش هيبوظ.

## ٣) بياناتك الشخصية

كل حاجة في ملف واحد: **`src/data/site.js`**

| إيه اللي تغيّره | فين |
| --- | --- |
| الاسم / اللوجو الحرفي | `name`, `nameEn`, `monogram` |
| الوصف والنبذة | `intro`, `about` |
| **رقم الواتساب** | `contact.whatsapp` ← بصيغة دولية من غير `+` مثال: `201012345678` |
| الإيميل | `contact.email` |
| السوشيال | `contact.socials` |
| الأرقام (سنين خبرة… إلخ) | `stats` |
| الخدمات وطريقة الشغل | `services`, `process` |
| أسماء العملاء | `clients` |
| البرامج | `tools` |

> ⚠️ **مهم:** الأرقام والإيميلات واللينكات الموجودة دلوقتي **أمثلة**.
> غيّرها ببياناتك الحقيقية قبل ما تبعت الموقع لأي كلاينت.

## ٤) الشكل والألوان

- الألوان والخطوط في أول `src/index.css` تحت `@theme`:
  - `--color-ink` الخلفية الغامقة، `--color-paper` لون النص،
    `--color-ember` اللون المميز (الأورانج).
- الخطوط: Cairo (عربي) و JetBrains Mono (تيكست تقني)، متحمّلة من Google Fonts
  في `index.html`. لو عايز خط تاني بدّله هناك.
- الشعار (favicon) في `index.html` — SVG بسيط تقدر تعدله.

## ٥) تبعته للكلاينت إزاي؟

**أفضل طريقة: لينك.** نزّل نسخة build وارفعها مجاناً في دقيقة:

1. `npm run build`
2. افتح [app.netlify.com/drop](https://app.netlify.com/drop) واسحب فولدر `dist`
   جوّه الصفحة → هيطلعلك لينك زي `mohamed-edits.netlify.app`.
3. (اختياري) من إعدادات Netlify اربط دومين باسمك.

بدائل: Cloudflare Pages، Vercel، GitHub Pages — كلهم بيقبلوا فولدر `dist`.

**بلاش** تبعته كفولدر ملفات عادي وتفتحه بدبل كليك — الفيديوهات مش هتشتغل
من غير سيرفر. لو مضطر، ابعته زيب + شرح إنه يتفتح بسيرفر محلي.

- [ ] غيّر رقم الواتساب والإيميل والسوشيال.
- [ ] شيل الفيديوهات الديمو وحط شغلك (على الأقل ٤–٦ أعمال).
- [ ] حط صورتك في `public/images/portrait.jpg`.
- [ ] عدّل أسماء العملاء في `clients` أو شيلها لو مش عايز تعرضها.
- [ ] جرّب الموقع على الموبايل (الفيديوهات والزرار).
- [ ] عدّل `title` و `description` في `index.html` لو غيّرت الاسم.

## هيكل المشروع

```
public/
  videos/          ← فيديوهاتك + البوسترات
  images/          ← صورتك
src/
  data/site.js     ← بياناتك ونصوص الموقع
  data/projects.js ← قايمة أعمالك
  components/      ← أقسام الموقع (هيرو، شوريل، أعمال، خدمات…)
  index.css        ← الألوان والخطوط والتأثيرات
  App.jsx          ← تركيب الصفحة
```
